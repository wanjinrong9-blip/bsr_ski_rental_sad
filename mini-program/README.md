用户提供的小程序备案号为**湘ICP备2026056763号-1X**；这是小程序备案，不表示网站域名 `bsrski.cn` 的备案、HTTPS 请求域名登记或小程序版本审核已经完成。

## 本机预览

1. 在应用根目录启动原网页服务：`node src/server.mjs`，确认 `http://127.0.0.1:4173/api/health` 可访问。此服务只监听电脑回环地址。
2. 用微信开发者工具导入本目录 `mini-program/`；`project.config.json` 与本机被 Git 忽略的 `project.private.config.json` 已使用正式 AppID。当前 `utils/config.js` 仍指向本机 `127.0.0.1`，开发者工具临时关闭请求合法域名校验，因此只适合电脑模拟器。不要把本机 HTTP 和关闭校验设置带入真机或发布配置。
3. 进入“选装备”，先选门店和挪威当地日期段，查询可租数量，再加入购物车。使用网页已有的**顾客账号**或在本机创建虚构演示顾客账号登录；不要输入真实个人资料。
4. 在购物车核对 NOK 租金与参考价值 8% 押金，阅读规则至底部，勾选同意并选择本次滑雪水平。提交后在“我的订单”生成并阅读合同、记录演示确认与演示付款；网页员工工作台准备装备后，小程序下拉刷新可见相同进度和处理人。若受损鉴定已上传照片，订单详情提供逐张查看入口；该功能目前通过本机接口和原生逻辑模拟测试，真机预览待验。
5. 运行纯逻辑检查：`node --test mini-program/tests/*.test.cjs`。

2026-11-25 在微信开发者工具 Stable 2.02.2609250 的“详情→基本信息”确认项目 AppID 为 `wx51ce51fc873371a6`、名称一致、发布状态为“未发布”；本机基础库设为非灰度的 3.17.6。正式 AppID 电脑模拟器显示目录 32 款规格；购物车展示一笔样例（租金 NOK 774、押金 NOK 384、合计 NOK 1158）；“我的订单”显示合成单 BR-DEMO004/003，BR-DEMO004 详情展示阶段、负责人 Emma Berg 与取货码区域；“我的”页展示小程序名称及用户提供的备案号。所查页面问题面板 0，编译错误 0。`node --test mini-program/tests/*.test.cjs` **15/15** 通过。本机演示库没有受损鉴定单，照片按钮尚未在模拟器中实际点击；照片下载与预览调用已通过原生逻辑及服务端权限测试，真机仍待验。

小程序的本机调试使用开发者工具电脑上的 `127.0.0.1`；真机的 `127.0.0.1` 指向手机自身，所以真机无法按此配置连接。默认演示暂用网页顾客账号密码；它**不是微信登录**。本机 SHOWCASE 合成数据和服务端独立小程序会话已具备代码与隔离测试；实际微信平台交换仍需私有 AppSecret、注册的 HTTPS 请求域名、对应服务端环境及受控发布。不能把含公开教学账号的 `demo` 部署到互联网，也不能仅靠客户端传来的 OpenID 确认身份。

## 安全展示模式源码（尚未接入真实账号）

[`config.example.js`](config.example.js) 是填写字段示意，包含公开的正式 AppID，域名仍是不可用的 `.invalid` 占位符，不含 AppSecret。待 HTTPS 请求域名登记及服务端私有配置完成后，再将 `mode: 'wechat-showcase'`、实际 `apiBase` 和同一 `appId` 写入运行配置；服务器另配置私有 AppSecret。默认 [`utils/config.js`](utils/config.js) 保持 `local-demo`，回环地址和关闭域名校验均不能带入真机或发布包。

安全模式下，“我的”调用 `wx.login`，服务端交换微信临时码；首次使用者输入现有顾客账号凭据并明确同意绑定。小程序保存独立会话，私有 `/api/mini/*` 请求使用 Bearer；退出或解绑清除本地私有缓存。本人订单的鉴定照片通过受保护的 `GET /api/mini/damage-photos/:id` 下载到临时文件，再调用微信图片预览；他人订单或匿名请求不能读图，退出时尝试删除已记录的临时文件。库存、购物车、报价、预约、合同及本人订单走相同业务库；报价与预约携带购物车版本及服务端报价 ID。安全模式拒绝网页账号直接登录和自助注册。未配置正式平台条件时客户端会拒绝连接，网站仍展示小程序筹备状态。

## 当前端点与同步边界

| 能力 | 共用服务端接口 | 本机演示行为 |
| --- | --- | --- |
| 日期段装备与单件库存 | `GET /api/catalog`、`POST /api/quote` | 每次按门店、取货/归还时刻重新查询；服务端再核对防超卖 |
| 顾客购物车 | `GET/PUT /api/cart` | 登录后两端共享购物车和版本；另一端更新时刷新当前版本，不静默覆盖 |
| 预约与订单 | `POST/GET /api/reservations` | 同一数据库、按顾客归属读取；网络不确定时用原 `Idempotency-Key` 找回 |
| 合同与进度 | 合同、订单详情、装备准备接口 | 顾客可看负责人、状态、取货码；签署与付款仅模拟 |
| 鉴定照片 | `GET /api/mini/damage-photos/:id`（安全模式）；本机模式使用受保护的 Web 照片接口 | 只允许订单本人读取，临时下载预览；本机授权与逻辑测试通过，真机待验 |

购物车在未登录时只保存在本机；登录时若网页账号已有购物车，用户会选择使用网页版还是覆盖为当前本机选择。网页和小程序的业务记录从同一数据库读取，页面刷新可见变化；当前未启用微信消息订阅或实时 WebSocket 推送。
