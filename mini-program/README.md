## 当前顾客账号体验

运行配置为 `account-showcase`，API为 `https://bsr-temporary-preview-production.up.railway.app`。导入本目录后，用项目所有者私下交接的顾客账号登录；账号与密码不在仓库中。小程序使用独立登录产生的受控Cookie会话，后续请求携带精确Origin；不使用公开教学密码、客户端OpenID或网页已有会话。只允许顾客工作台；账号停用、会话失效或退出会清除私有状态。HTTPS、服务器域名校验保持启用，平台合法请求/下载域名及真机访问须另验。

这不是wx.login或微信身份绑定。正式 `wechat-showcase` 模式保留独立Bearer、微信临时码交换、显式顾客绑定及解绑的实现，待服务端私有配置、合法域名与真机验收完成后启用。`local-demo`模式仅允许开发者工具连接电脑回环接口，不能作为手机体验包配置。

## 可体验流程

1. 选择门店及挪威日期段，09:00起租、归还日16:00前还件；查询整段可订量，筛选款式/尺码并加入购物车。
2. 登录后两端共用顾客购物车与版本；预约前列出资料缺项，可跳转“我的”补全。选择本次水平，阅读并同意当前损坏/超时规则。
3. 提交形成有限期暂留；生成并核对当前合同快照、本人确认后，按独立付款卡核对NOK分项再模拟付款。付款成功才生成备货任务。
4. 查看具名备货、交付、逐件归还、24小时初评与费用状态；受保护的鉴定照片只允许订单本人读取。初评反馈不是维修完工。
5. 在受损复核/待补差阶段可提交本人费用异议，网络不确定时用同一标识重试。未解决争议暂停最终结清；已完成订单不自动重开。

支付、退款、联系及签署均为课程模拟，不发生真实资金流转或合格电子签署。请勿填写真实个人资料或上传真实照片。
