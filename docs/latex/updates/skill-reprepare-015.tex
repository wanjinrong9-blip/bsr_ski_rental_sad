\subsection*{H.1 涉众利益与前后条件}

顾客须在每次线上预约中明确提供本次滑雪水平；现场开单时由租赁专员向顾客取得自评后录入。水平属于该笔订单的事件字段，不是装备规格的固定适用等级，也不能由系统从历史资料推断。顾客利益是匹配信息真实、合同可核对；门店利益是备货判断有依据；管理人员利益是统计不被默认值污染。历史空值在读取时说明为“历史未登记”，不回填原订单或改写合同。

准备单的当前处理人或所属门店经理可将未交付订单退回重新拣选，但须提交当前版本和至少 3 字公开说明。顾客本人应能看到进度、处理人和说明；原准备单失效的单件绑定不能继续占住库存。已经交付、已关闭或不属于本店的订单不满足前置条件。

\subsection*{H.3 分析到数据与表示层的映射}

预约订单保存\emph{顾客本次水平}，合同快照复制该历史事实；空值只在读取投影转换为“历史未登记”。准备单记录状态、版本、处理人、时间和公开说明；准备单件的有效绑定及逐项检查属于本次准备，重新准备使旧绑定和旧勾选失效。重新拣选调用当前可用库存判断，并在单一业务事务内提交准备状态及占用变更。现有表和版本字段可承载这一修订，不要求新表迁移。

顾客端与现场开单界面均显示无预选的必填水平选择；顾客订单进度展示重新备货的公开原因和当前处理人。失败反馈应保留原表单草稿。执行者不得看到其他顾客订单的内部备注。追溯：005 复核缺口 → 015 FR-001--009 → 预约及准备接口契约 → SC-001--005。
