## 准备中的架构

016 的顾客本人换装确认与主数据原子写入已在本机通过完整 Node 127/127 和隔离浏览器验收。017 的候选代理入口已完成本机演练：专项 **3/3**、完整 Node **130/130**，隔离演示、直连候选和代理浏览器通过，临时库重启、备份与恢复通过。候选库初始为空、预约关闭，只用于验证身份和安全入口。018/019 已在本机以独立 SHOWCASE 合成库完成六角色租赁及 Web/Mini HTTP 同单流程；最近全量 Node **220/220**、2026-11-25 原生逻辑 **15/15**。正式 AppID 已在微信开发者工具电脑模拟器核对，微信登录与扫码仍默认 OFF。已另备 SHOWCASE 私有环境、systemd 与 Nginx 模板；这些模板尚未在 Ubuntu 或云端验证。真实收款、退款、合格电子签署和正式 BSR 规则仍未接入或获批。

中国内地服务器的网站域名上线需办理适用备案；本实例的当前订单状态应以阿里云备案控制台为准。[轻量备案说明](https://help.aliyun.com/zh/simple-application-server/user-guide/apply-for-an-icp-filing-for-a-domain-name) 若后续增加数据盘，需另行初始化、挂载并配置重启自动挂载，不能直接沿用系统盘模板。[数据盘指南](https://help.aliyun.com/zh/simple-application-server/user-guide/attach-a-data-disk) 快照须与 SQLite 应用一致性备份配合。[快照说明](https://help.aliyun.com/zh/simple-application-server/user-guide/manage-snapshots)

轻量应用服务器使用自己的**防火墙规则**，不是 ECS 安全组；已将原来开放的 80/443 禁用，22 和 ICMP 仍开放。不要在管理来源未确认时直接关闭 22，以免锁定服务器。发布前保持 Web 入口关闭；正式决定后才审阅必要的 HTTPS 规则，内部应用端口继续关闭。[轻量防火墙指南](https://help.aliyun.com/zh/simple-application-server/user-guide/manage-the-firewall-of-a-server) 证书必须覆盖实际域名，并在 Nginx 上验证。[阿里云证书指南](https://help.aliyun.com/zh/ssl-certificate/install-ssl-certificates-on-nginx-servers-or-tengine-servers)
