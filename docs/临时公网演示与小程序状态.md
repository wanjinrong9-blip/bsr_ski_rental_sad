采用仓库根目录 `render.yaml` 或手动新建免费 Docker Web Service，Dockerfile 为 `deploy/render/Dockerfile`，构建上下文为仓库根目录，健康检查为 `/api/health`。实例必须选 **Free**，不添加付费磁盘。
