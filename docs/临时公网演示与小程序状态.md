## 为什么小程序仍不能直接访问

1. 小程序备案已完成，项目所有者提供备案号为 湘ICP备2026056763号-1X，AppID 为 wx51ce51fc873371a6。备案完成不等于代码审核通过或正式发布。
2. 开发包 0.1.1 已上传，打包质量问题已修复；目前没有取得审核通过、发布成功的证据。
3. 当前小程序交付包仍为本机开发配置，后端地址为 http://127.0.0.1:4173。老师的手机不能通过该地址访问开发电脑。
4. 真实微信登录仍需服务端私有配置、获平台认可的 HTTPS 合法请求域名、账号绑定和真机联调。临时网页上线不会自动补齐这些条件，也不能直接认定 Railway 地址可用于已发布小程序。
5. 正式扫码入口需要对应已发布版本、微信签发的小程序码及真机验证。目前网页显示“小程序筹备中”，不提供冒充正式小程序码的二维码。

本次先提供完整网页临时演示；小程序保留源码与开发工具验证成果，正式后端和平台条件齐备后继续审核发布及两端联调。

## 网站备案通过后的替换顺序

1. 在已购阿里云轻量服务器部署隔离数据空间，完成容量、持久存储与异机备份恢复验证。
2. 核对 bsrski.cn 网站备案，配置 DNS、HTTPS、代理边界和必要防火墙，验收网页六角色流程。
3. 更新 GitHub 的正式访问地址并通知老师切换；临时合成记录不作为真实业务资料迁入。
4. 按微信平台要求配置正式请求域名和服务端私有凭据，重新构建小程序，验收真实登录、双端同步和扫码后再审核/发布。
5. 正式地址验收并通知完成后停止 Railway 临时实例，撤销临时账号及种子。NOK 记账、8% 押金和历史订单政策不因迁移改变。
