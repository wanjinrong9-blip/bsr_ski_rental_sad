# Feature Specification: 受控 HTTPS 入口的本机演练

**Feature Directory**: `specs/017-trusted-proxy-rehearsal`  
**Created**: 2026-11-18  
**Status**: 本机自动化、代理浏览器与恢复演练通过；阿里云部署和业务方验收未开始  
**Input**: 用户计划自行购买阿里云服务和域名，要求先完成其余准备工作；016 后续部署缺口是正式候选用途只能本机直连 HTTPS，尚不能安全地经受控反向代理访问。

## User Scenarios & Testing

### User Story 1 - 管理员能在开放入口前核查可信部署边界（Priority: P1）

系统管理员准备单实例候选环境时，能先配置唯一对外 HTTPS 来源、只向本机开放的应用入口和受信任代理凭据。缺项、弱凭据、错误地址或误把课程演示资料当候选资料时，服务在接收请求和创建业务数据前拒绝启动；原有本机直连方式仍可使用。

**Why this priority**: 对外服务若错误信任来源或演示账号，随后所有角色权限检查都无法弥补入口风险。

**Independent Test**: 使用完全独立的临时目录，逐项构造正确和错误的部署配置；检查监听地址、进程结果和数据库文件前后状态。

**Acceptance Scenarios**:

1. **Given** 候选资料空间与安全配置均有效，**When** 管理员选择受控代理入口，**Then** 应用只在本机接受代理转发，对外 HTTPS 来源唯一且可核对，私有数据路径不进入公开资源目录。
2. **Given** 代理凭据、对外来源、候选资料路径或监听边界任一不合要求，**When** 管理员尝试启动，**Then** 系统拒绝并指出配置类别；不创建候选业务数据库，也不监听外部网卡。
3. **Given** 既有本机候选直连配置或课程演示配置，**When** 使用旧启动方法，**Then** 其原有安全限制和可见功能不发生变化。

---

### User Story 2 - 已授权账号经代理访问且伪造请求被隔离（Priority: P1）

已被管理员开通的候选账号在本机 HTTPS 代理演练入口登录、查看本人允许的数据和退出。服务只接受该受信任代理转发的请求；没有凭据、伪造外部地址、冒充另一客户来源或错误网页来源的请求不能读取受保护内容或产生业务写入。同一代理背后的两名客户各自受到独立的登录尝试限制。

**Why this priority**: 云端入口会把原有直连 HTTPS 改为代理终止加密；身份会话和来源限速必须仍按真实的隔离边界工作。

**Independent Test**: 在隔离资料空间启动仅本机可见的 HTTPS 测试代理和候选应用，用两个独立客户标识完成登录与失败尝试，同时提交伪造请求并核对审计与资料差异。

**Acceptance Scenarios**:

1. **Given** 代理和候选账号已初始化，**When** 账号通过正确外部 HTTPS 来源登录，**Then** 浏览器只收到安全会话 Cookie，后续读取只见该角色允许的数据；注销或停用后旧会话不可用。
2. **Given** 请求绕开代理、缺少代理凭据、外部主机不符或以绝对网址试图改写目标，**When** 请求到达应用，**Then** 在业务处理前拒绝，且不返回受保护资料。
3. **Given** 恶意客户传入伪造的来源地址或网页来源，**When** 代理转发，**Then** 仅代理核实后提供的客户地址参与限速；错误网页来源的写入被拒。
4. **Given** 甲和乙从同一代理访问，**When** 甲触发来源限速，**Then** 乙在其自身账号和来源正常时仍能登录。

---

### User Story 3 - 部署操作者拿到可复核的阿里云准备材料（Priority: P2）

在购买阿里云服务与域名之前，部署操作者能检查拟用单实例、持久数据盘、HTTPS 代理、备份和恢复步骤，以及哪些动作必须等实例地域、域名和证书确定后才能执行。准备材料不得含演示数据库、真实顾客信息、密钥或可直接打开公网的配置。

**Why this priority**: 可审阅的配置与恢复流程能减少购买后现场拼接设置造成的资料遗失或意外开放。

**Independent Test**: 在无云账号、无公网监听的本机检查配置样例与发布前核对表，使用隔离候选库进行重启、备份与恢复演练。

**Acceptance Scenarios**:

1. **Given** 仍未购买实例和域名，**When** 操作者查看部署材料，**Then** 能辨明应用本机端口、代理 HTTPS 入口、私有持久目录、独立备份位置及安全组开放条件。
2. **Given** 单实例候选库已存在，**When** 本机模拟重启与备份恢复，**Then** 候选来源仍可验证，私有资料未从公开目录读取，旧会话按恢复策略处理。
3. **Given** 尚未选择 ECS 地域或域名，**When** 准备部署包，**Then** 必须保留域名、证书、ICP备案、数据盘挂载和公网授权的待办状态，不得宣称已上线。

### Edge Cases

- 代理凭据为空、过短、含换行、与已知占位值相同，或放在公开资源目录中，均不得启用代理入口。
- 多重、重复或格式错误的 Host、客户地址和来源字段不得由应用自行猜测哪一个可信；不可信请求在业务路由前拒绝。
- 代理健康检查和静态文件请求也属于入口边界；不能因它们是只读请求就绕过代理校验。
- 长连接、浏览器刷新与旧候选会话在代理后仍按既有账号权限和撤销规则处理。
- 代理模式仍使用空候选目录和未批准交易阻断；不得把本地演示密码或合成订单导入候选资料空间。

## Requirements

### Functional Requirements

- **FR-001**: 系统须提供显式受控代理入口选项，并保留现有本机直连候选与本地演示选项；未显式启用时不得改变旧行为。
- **FR-002**: 受控代理入口须只接受本机代理连接，并在全部业务和静态路由之前校验唯一 HTTPS 对外来源、目标主机与不可猜测的代理凭据；任何校验失败须拒绝且不泄露业务内容。
- **FR-003**: 受控代理入口的无效配置须在打开或建立候选数据库之前失败；演示资料空间、公开资源目录及私有备份目录仍须相互隔离。
- **FR-004**: 系统只能采用受信任代理清洗并标记的客户地址进行来源限速；不能直接信任访客提交的转发头。不同客户限速须隔离。
- **FR-005**: 候选登录、退出、权限、会话撤销、首次改密与写入来源限制在受控代理入口下继续生效；会话 Cookie 仍只面向 HTTPS 且不能由脚本读取。
- **FR-006**: 候选未批准目录、预约、支付、退款、合同签署和换装的交易阻断须保持；受控代理入口不能成为课程演示模式对外开放的捷径。
- **FR-007**: 交付的部署准备材料须明确单实例写入、私有持久数据盘、应用一致性备份与隔离恢复、代理证书、最小网络开放及待确定的地域/域名事项；样例不得含真实或演示凭据。
- **FR-008**: 对入口失败、来源伪造、账号限速、重启和恢复的验证须使用临时资料空间；不得修改现有运行演示库或创建公网入口。

### Key Entities

- **入口配置**：预期外部 HTTPS 来源、应用监听地址、受控代理凭据及所选用途；属于部署配置，不成为业务订单资料。
- **可信请求上下文**：经代理校验的目标主机、客户地址、网页来源和内部连接；只在该请求生命周期中有效。
- **候选资料空间**：与演示库隔离的账号及审计数据；017 不新增业务表或导入演示订单。
- **部署核对记录**：可复核的配置、备份和恢复检查结果，不包含密钥值或个人资料。

## Success Criteria

### Measurable Outcomes

- **SC-001**: 至少 12 类缺项、弱值、错误来源和错误路径配置全部在启动前被拒绝；原有本机直连与演示入口各保持一条成功基线。
- **SC-002**: 至少 20 个绕过、伪造、重复头和错误来源请求在隔离演练中不能读取受保护数据或产生业务写入；合法候选账号可登录、读取本人允许内容并退出。
- **SC-003**: 同一代理后的两名客户分别进行失败登录；甲达到阻断阈值时，乙可继续正常登录，且安全会话性质和既有角色限制不退化。
- **SC-004**: 隔离候选库完成一次重启与一次一致性备份/恢复，完整性通过、外键错误为 0、旧会话按恢复策略失效；演示运行库字节和行数均不变。
- **SC-005**: 原有完整自动回归及本机浏览器流程通过；演练中公网监听数量为 0，GitHub 和云服务创建数量均为 0。

## Assumptions

- 用户将来可能选择阿里云单台 Linux ECS 与域名；具体地域、实例、证书和预算尚未确定。本包使用本机模拟入口，不把任何云平台配置视为已生效。
- 对外 HTTPS 由受控代理终止，应用保持回环监听。代理仅在同机访问应用并覆盖清洗与安全相关的入站头。
- 当前候选模式的目录与交易能力未获 BSR 批准，继续保持关闭；正式全功能合成数据预览另设后续工作包。

## Out of Scope

- 购买阿里云 ECS、域名或证书；ICP备案、DNS 解析、安全组实际开放、GitHub 上传、公网部署与真实顾客数据迁移。
- 将课程演示账号、已知密码和合成业务数据作为可公开访问的完整功能演示。安全的全功能合成数据预览另列 018。
- 真实支付退款、合格电子签署、BSR 正式价目、商业批准与多实例数据库负载。
- 修改业务用例、类图、ERD 或论文风格的核心设计需求 PDF；本包只更新独立部署准备文档与 Spec Kit 记录。
