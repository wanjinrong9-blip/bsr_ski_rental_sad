# Feature Specification: 本地预览启动安全闸门

**Feature Branch**: `013-local-preview-startup-guard`（Spec Kit 逻辑标识；当前项目未初始化 Git）  
**Created**: 2026-11-11  
**Status**: 本地实现与验收完成（2026-11-11）；正式云端部署仍有独立缺口  
**Input**: 本地演示账号使用固定种子密码，SQLite 存有会话、顾客资料和受损照片；实施前启动代码直接采用 `HOST`、`PORT`、`BSR_DB_PATH`，没有本机地址和公开目录检查。对应项目宪章 IV、V 与 NFR-01/06。

## 用户场景与验收

### US1 只在本机启动课程预览（P1）

学生从自己的 PowerShell 启动服务，默认访问 `http://127.0.0.1:4173`。需要调整本机端口或 IPv6 回环地址时，仍可在明确允许的范围内启动；配置成对外地址或无效端口时，程序在读取/创建数据库和监听前失败。

**独立验收**：使用隔离临时数据库逐项启动子进程。省略 `HOST`/`PORT`、设置 `HOST=127.0.0.1`、`HOST=::1` 或 `HOST=localhost` 且端口有效时，可以只从本机访问健康接口；设置 `HOST=0.0.0.0`、`HOST=::`、局域网/公网 IP、其他域名、带空格或空字符串时，非零退出，不生成数据库、不占用目标端口。

### US2 数据库不能落在公开静态目录（P1）

学生把 `BSR_DB_PATH` 设为项目 `public` 内文件、嵌套新目录、大小写变体，或通过已存在的父目录符号链接/Windows junction 指向 `public`。系统在任何数据库创建、目录创建或监听之前拒绝；错误提示说明数据库路径不可位于公开目录，但不回显敏感绝对路径。合法的 `data/` 或隔离临时目录仍可启动，原有数据不改写。

**独立验收**：对每个拒绝场景比对启动前后的目录树，确认没有新数据库、WAL、SHM、父目录或监听；通过 `public` 的词头相似兄弟目录（如 `public-backups`）不得误拒。已有数据库文件的符号链接和不存在文件的符号链接父目录都要验证。

### US3 清楚区分本地演示与正式部署（P2）

学生或老师阅读启动日志、README 与需求审计时，能确认安全闸门只限制当前课程演示进程的本机监听及数据库路径，不能据此宣称已具备云端访问、正式身份认证、真实支付或生产隐私合规。未来云端架构须另拟规格和安全验收，不通过设置 `HOST=0.0.0.0` 绕开本地闸门。

### US4 公开静态文件不能通过链接读取私有文件（P1）

访客请求 `public` 下的静态文件时，服务只返回最终真实路径仍位于 `public` 内的文件。若 `public` 内的符号链接或 Windows junction 指向项目数据库、备份、配置或其他外部文件/目录，请求明确拒绝，不得将文件正文或部分内容返回。普通 HTML、CSS、JS、图片仍正常访问。

**独立验收**：在隔离副本的 `public` 内创建指向外部测试文件的链接和指向外部目录的链接，GET/HEAD 均返回拒绝响应，响应体不含外部文件内容；正常静态文件与站点入口仍可访问。链接无法创建时记录环境限制并在具备权限的环境补验，不把跳过当作通过。

## 功能要求

- **FR-001**：启动时先验证配置，再调用 `openDb`、创建数据库目录、初始化数据库或调用 `server.listen`；任一验证失败以非零退出码终止，向标准错误输出不含秘密的原因。
- **FR-002**：省略 `HOST` 时使用 `127.0.0.1`；显式值仅允许 `127.0.0.1`、`::1`、`localhost`。拒绝通配地址、局域网/公网 IP、其他域名、空白和附带协议/端口的值。`localhost` 按字面白名单处理，不做 DNS 反查放行其他名称。
- **FR-003**：省略 `PORT` 时使用 `4173`；显式值必须是十进制整数 `1`～`65535`，拒绝空白、负数、`0`、超范围、小数、指数形式、`NaN` 和非数字。合法非默认端口继续可用。
- **FR-004**：省略 `BSR_DB_PATH` 时沿用 `data/bsr.sqlite`。显式相对路径沿用当前进程工作目录解释；验证时先转为绝对路径，不因验证改变原有路径语义或覆盖历史数据库。
- **FR-005**：拒绝数据库目标文件位于 `public` 本身或任意后代路径，包括尚未创建的后代目录；使用路径段边界判断，不把 `public-backups` 等兄弟目录误判为后代。
- **FR-006**：对静态 `public` 目录和数据库目标，既比较词法绝对路径，也把候选路径的最深已存在祖先解析为真实路径，再拼接尚未创建的尾段比较；已有目标文件、父目录符号链接和 Windows junction 都应被识别。Windows 路径比较按大小写不敏感处理。验证中不创建目录或文件。
- **FR-007**：危险配置的失败应发生在任何数据库或网络副作用之前；拒绝后没有新 SQLite 主文件、WAL/SHM、目录或监听。默认启动、已有合法数据库、测试隔离库和本机访问体验保持可用。
- **FR-008**：启动帮助与 README 明确此闸门仅适用于本地演示。正式云端部署需重新设计认证、秘密管理、数据库、网络入口、日志与备份，不将“允许回环”解释为云端部署方案。
- **FR-009**：`serveStatic` 对实际将读取的目标文件（包括 SPA 入口回退）执行真实路径公开目录边界检查。`public` 内链接解析到外部文件或目录时返回拒绝，不读取、不回传目标内容；不能仅依赖 URL/词法路径包含检查或 `stat()` 的跟随链接结果。正常静态资源仍可访问。

## 边界与质量要求

- 测试要覆盖 Windows 路径大小写、混合分隔符、`..`、嵌套新目录、已存在父目录符号链接/ junction、已有数据库文件符号链接、公开目录词头相似兄弟路径，以及端口边界 `1`/`65535` 与无效值。另覆盖静态文件/目录链接逃逸、GET/HEAD 拒绝和正常静态资源读取。符号链接测试若宿主权限不允许创建，须记录跳过原因并在具备权限的环境补验，不把跳过写作通过。
- 失败路径不得调用备份工具，也不得写入运行数据库；现有在线备份及恢复机制不在本特性中修改。
- 本特性不提供反向代理、TLS、公网监听、正式账号管理、秘密轮换或云端发布。硬链接等无法仅凭路径解析识别的非路径别名，列为后续正式部署文件权限审计范围；不能声称闸门已封闭所有文件系统别名。
- 012 门店对象授权、演示资金与当时的 67 项自动测试是实施前基线；013 增量测试 4/4、全套回归 71/71、本地浏览器冒烟及恢复演练的实际结果见 [quickstart.md](quickstart.md)。自动测试不替代正式身份认证或云端部署验收。
