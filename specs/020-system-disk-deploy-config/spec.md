# 020：单系统盘部署配置准备

日期：2026-11-26。执行者为部署操作员；价值是从同一套模板生成互相一致的 Node/Nginx 私有配置，减少手工抄错代理密钥导致入口拒绝的情况。

- FR-020-01：提供离线 `render` 与 `check` 命令，只接受 `bsrski.cn` 及其合法子域名。
- FR-020-02：一次生成一个随机 256 位代理密钥，写入 env 与 Nginx include；不输出密钥，不自动配置微信私钥。
- FR-020-03：只在仓库外、已有私有父目录下创建全新目录；禁止覆盖、链接回仓库和读取链接配置文件。POSIX 目录 0700、文件 0600；Windows ACL 单独核验。
- FR-020-04：保留回环端口 4175、系统盘私有路径及微信入口 OFF；检查域名、全部文件及模板一致性，拒绝多余文件、占位符、篡改和不匹配密钥。
- AC-020-01：成功生成后独立 `check` 通过；失败不覆盖已有文件，输出不含密钥。测试只用一次性临时目录。

范围外：连接阿里云、传送配置、服务启用、防火墙开放、证书申请、ICP备案确认、实际 nginx/systemd 语法及容量验收。域名仍在审核；不创建真实部署密钥或修改运行数据库。
