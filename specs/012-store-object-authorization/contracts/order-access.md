# 订单对象访问契约

| 路径/动作 | 顾客 | 自店员工/经理 | 外店员工/经理 | 经营负责人/平台管理员 |
| --- | --- | --- | --- | --- |
| `GET /api/reservations` | 本人列表 | 本店列表 | 不列出外店 | 不返回单笔列表 |
| `GET /api/reservations/{id}` | 本人详情 | 本店详情 | 拒绝 | 拒绝 |
| 合同、备货、受损、照片、核价、交付等关联接口 | 本人可用动作 | 本店岗位动作 | 拒绝完整资料/操作 | 不获得业务详情/代办权 |
| `GET /api/operations/lookup?code={exact}` | 不适用 | 本店正常核对 | 仅 `ACTIVE` 时返回最小异店归还资料 | 不适用 |
| `POST /api/operations/return` | 不适用 | 本店逐件归还 | 需再次提交精确码，服务端固定接收门店，返回最小回执 | 不适用 |
| 订单提醒 | 本人业务通知按原规则 | 本店逐笔待办 | 不列出外店 | 按门店/状态聚合计数，无逐笔记录 |

## 门店人员与库存查询范围

| 接口 | 店员 | 经理 | 经营负责人/管理员 |
| --- | --- | --- | --- |
| `GET /api/employees` | 本店员工与可受派技师候选 | 本店员工与可受派技师候选 | 按岗位管理范围读取员工资料 |
| `GET /api/shifts` | 本人班次 | 本店班次 | 只读岗位范围另行约束 |
| `GET /api/roster` | 本人行 | 本店每日排班；传其他门店拒绝 | 只读岗位范围另行约束 |
| `GET /api/inventory` | 本店逐件实物 | 本店逐件实物 | 按门店/状态聚合数量，不含逐件资料 |
| `GET /api/inventory/summary` | 跨店聚合数量 | 跨店聚合数量 | 跨店聚合数量 |

异店查找响应只含订单标识/编号、当前租赁状态、约定归还时刻、未还单件的 ID、库存号、名称与尺码，以及本店接收门店标识；不得含顾客身份、电话、邮箱、地址、取货码回显、单笔金额、合同/押金/照片/历史订单或内部备注。错误码、非 `ACTIVE`、模糊输入和权限不足均不给外店业务正文。

异店归还请求除订单 ID、归还单件与条件/备注外，必须提供该单完整订单号或取货码供服务端重验；传入与当前员工所属店不同的 `returnStoreId` 一律拒绝。旧接口不应接受仅凭可猜测订单 ID 的异店提交。成功响应只含本次接收事实、受理时间、归还门店和所收单件，不包含完整订单详情。
