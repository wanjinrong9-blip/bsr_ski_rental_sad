# BSR 滑雪租赁公司 —— 租赁管理系统 系统分析与设计

中南大学《系统分析与设计》课程案例作业（Ivey 案例 W50242：BSR Ski Rental）。

按建模工作流组织：**线上调研 → 业务建模 → 需求 → 分析 → 设计**。
完整文档：[设计需求文档（PDF）](./BSR滑雪租赁公司-设计需求文档.pdf)

## 工件一览
- 愿景、用例图与用例规约（UC01–UC10）
- 业务用例图 / 业务序列图 / 现状与改进
- 分析类图、分析序列图、分析状态机图
- 设计：数据层（55 表 ERD，六业务模块）、业务层（代码映射）、表示层
